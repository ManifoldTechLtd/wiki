# 4. 电源与连接

## 4.1 外部供电系统设计指南

1. **电压范围要求**

   Odin1 Lite 标称工作电压为 **DC 9-24V**，建议使用 **12V / 2A** 直流适配器（≥ 24W 功率裕量），否则可能因瞬时电流不足导致设备无法正常启动或工作不稳定。

2. **电源适配注意事项**

   - 通过 **电源数据一分二航插线** 的 DC 头接入适配器，DC 头规格为 **5.5×2.1mm**。
   - Odin1 Lite **出厂不标配电源适配器**，用户需自行准备符合规格的 12V 适配器。

3. **电压浪涌防护警告**

   ⚠️ 电源线路上超出额定上限的电压波动可能导致设备永久性损坏，建议在供电回路中增加过压保护电路。

4. **功耗特性说明**

   | 工作状态 | 功率特性 |
   |:-:|:-:|
   | 稳定运行 | 典型 ≈ **11** W |
   | 冷启动峰值 | 最大 **24** W |

5. **电源选型关键参数**

   - 持续输出能力 ≥ **2A**
   - 推荐功率裕量 ≥ **24W**
   - 过压保护阈值建议 ≤ **26V**

## 4.2 连接步骤

Odin1 Lite 通过以太网与 PC 通信。

1. 将 **电源数据一分二航插线** 的航插头按卡槽方向插入 Odin1 Lite 接口，并锁紧螺纹环。
2. **DC 头** 接入 12V/2A 适配器并通电；设备指示灯常亮代表上电成功。
3. **RJ45 网线** 接入 PC 网口（或交换机）。
4. 将 PC 网卡 IP 配置为 `192.168.1.x/24`（与设备 `192.168.1.251` 同网段）。
5. 通过 `ping 192.168.1.251` 确认通讯正常后即可启动驱动或访问 HTTP Dashboard。

> 🔧 关于网络配置的详细步骤参见 [7. Odin1 Lite 快速启动（Ubuntu）§7.2.3 网络配置](7.%20Odin1Lite%20Quick%20start%20for%20ubuntu#723-网络配置)。
