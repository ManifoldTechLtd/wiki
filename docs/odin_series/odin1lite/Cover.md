> Odin1 Lite 是一款集 LiDAR + RGB 相机 + IMU 于一体的紧凑型空间记忆模组（**单目 RGB**），采用 **以太网连接**（出厂 IP `192.168.1.251`），提供 ROS1 / ROS2 驱动及 HTTP Dashboard。

---

## 快速入门

1. 设备上电 → 网线接 PC → PC 设为 `192.168.1.x/24`
2. 浏览器访问 `http://192.168.1.251:8080` 查看设备状态
3. 部署驱动：参见 [7. Odin1 Lite 快速启动（Ubuntu）](7.%20Odin1Lite%20Quick%20start%20for%20ubuntu)
