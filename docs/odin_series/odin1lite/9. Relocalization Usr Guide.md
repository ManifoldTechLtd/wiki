# 9. 重定位功能使用说明

## 9.1 说明

Odin1 Lite 支持以下工作模式，通过 ROS 服务 `device_mode` 进行切换：

| mode | 模式 | 说明 |
|:-:|:--|:--|
| 0 | Standby | 待机 |
| 1 | Normal | 正常运行（默认）|
| 2 | Upgrade | 升级模式 |
| 3 | SLAM | 建图模式，驱动同时切换算法到 Build 模式 |
| 4 | Relocation | 重定位模式，驱动同时切换算法到 Reloc 模式 |
| 5 | ReMap | 重定位 + 增量建图模式，在已载入地图基础上扩展地图 |

> 重定位 / ReMap 由 **ROS Driver** 和 **算法 deb 包（`manifold-lc-sdk`）** 共同提供。仅部署 ROS Driver 时，设备可正常输出点云、图像、IMU、里程计等数据，但无法运行建图、重定位和增量建图算法。
>
> 请确保固件已升级到最新版本。

## 9.2 使用教程

### 9.2.1 前置条件

1. 已获取、编译并启动与设备固件版本匹配的 ROS Driver。
2. 已安装与当前主机平台匹配的 `manifold-lc-sdk` 算法 deb 包：

   ```bash
   # 在运行 ROS Driver 的主机上执行检测脚本
   chmod +x download_lc_sdk.sh
   ./download_lc_sdk.sh

   # 从脚本输出的 [Download links] 下载 RECOMMENDED 的 deb 包后安装
   sudo dpkg -i manifold-lc-sdk_<version>_<architecture>.deb
   ```

   检测脚本位于 [download_lc_sdk.sh](assets/code/download_lc_sdk.sh)。该脚本仅输出适用的下载链接，不会自动下载或安装 deb 包。

3. 已通过 SLAM 模式保存可用地图文件，并确认其主机本地路径。

4. 在启动 ROS Driver 的终端或新终端中加载 ROS 环境：

   ```bash
   cd ~/catkin_ws
   source install/setup.bash
   ```

### 9.2.2 建图（SLAM）

```bash
# Step 1: 切换到 SLAM 建图模式
ros2 service call /manifold/device0/device_mode \
    odin_ros_driver_rev1/srv/DeviceMode "{mode: 3}"

# Step 2: 移动设备采集地图...

# Step 3: 采集结束后保存地图
ros2 service call /manifold/device0/save_map \
    odin_ros_driver_rev1/srv/SaveMap "{path: '/tmp/odin_map.bin'}"

# Step 4: 切回 Normal 模式
ros2 service call /manifold/device0/device_mode \
    odin_ros_driver_rev1/srv/DeviceMode "{mode: 1}"
```

> ❗ 建图过程中请勿直接 `Ctrl+C` 退出驱动，必须先调用 `save_map` 保存地图。

### 9.2.3 重定位（Relocalization）

```bash
# Step 1: 切换到重定位模式
ros2 service call /manifold/device0/device_mode \
    odin_ros_driver_rev1/srv/DeviceMode "{mode: 4}"

# Step 2: 加载之前保存的地图
ros2 service call /manifold/device0/load_map \
    odin_ros_driver_rev1/srv/LoadMap "{path: '/tmp/odin_map.bin'}"

# Step 3: 移动设备，等待重定位成功...

# Step 4: 重定位完成后切回 Normal
ros2 service call /manifold/device0/device_mode \
    odin_ros_driver_rev1/srv/DeviceMode "{mode: 1}"
```

### 9.2.4 确认重定位结果

`load_map` 服务成功返回仅表示地图已被算法会话加载。加载后请移动设备一段距离，并根据应用侧的定位状态与位姿输出确认重定位是否收敛。

> ⚠️ Odin1 Lite 无法在静止状态下完成重定位；请勿在设备静止时判断重定位失败。

## 9.3 注意事项

- 地图保存依赖算法回环会话已就绪（设备已连接且标定可用），会话未就绪时服务返回 `error_code` 非 0
- `mode` 超出 0–5 范围时服务返回 `kInvalidArgument`
- 设备未连接时服务返回 `kNotInitialized`
- 请用 `ros2 service list` 确认实际服务名；v3.x 设备型号不再出现在话题/服务路径中
