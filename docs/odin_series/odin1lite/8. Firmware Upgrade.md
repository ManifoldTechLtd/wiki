# 8. 固件升级

Odin1 Lite 提供两种升级途径：**HTTP Dashboard（推荐）** 与 **SDK 命令行工具**。

## 8.1 固件获取

Odin1 Lite 固件请通过下方下载页面获取最新固件包及对应的版本说明。

| 项 | 信息 |
|:--|:--|
| 固件下载页 | [https://version.manifoldtech.cn/download/o1l](https://version.manifoldtech.cn/download/o1l) |
| 文件格式 | `.bin`（HTTPS OTA / SDK CLI 通用） |

## 8.2 固件更新内容

固件版本更新说明请咨询留形技术支持获取。

## 8.3 配套 ROS Driver 更新内容（v3.7.0 / 20261016）

1. 新增 loop-closure 可视化话题，发布载入地图、关键帧矫正结果、优化结果及里程计轨迹。
2. 新增 ReMap 模式（`device_mode=5`，`OdinDeviceMode` 新增 `kReMap`）：支持基于已载入地图扩展建图；主机端 loop_closure 切换到 ReMap，固件数据源处理与 SLAM 一致；`SaveMap`/`LoadMap` 说明更新为支持 ReMap；新增 corrected loop-closure 点云发布。
3. 恢复 `map_cloud` 回调注册；RViz 以三层色阶区分载入、矫正和优化点云，并显示连续里程计轨迹。
4. 修复 `map_cloud` 坐标系和 RViz 轨迹残留时间，恢复 SDK 算法控制与回调互斥锁分离。
5. ROS service 返回消息和日志改用 `OdinResultStr` 枚举名，替代裸错误码。
6. 新增 `ExployMap` 闭环地图导出接口：loop-closure 插件 ABI、SDK `ExployMap` API 及 ROS1/ROS2 `exploy_map` service 完成透传；具体导出格式由插件实现。
7. 增加 openssl 和 crypto 的静态库。

### v3.2.0 以来的重要变更

- **v3.6.0 / 2026-09-30**：
  - 增加 FFmpeg H.264 解码器运行时硬件加速自动检测与动态解码器发现（NVDEC/CUVID/VAAPI/VDPAU），硬件解码失败时自动回退到软件解码。
  - 增加 VAAPI/VDPAU 硬件解码支持（Intel/AMD GPU），并支持通过环境变量 `ODIN_CUDA_DEVICE` / `ODIN_VA_DEVICE` / `ODIN_VDPAU_DEVICE` 指定设备节点。
  - 增加 libyuv 可选集成，加速 YUV→BGR 转换（H.264/JPEG 解码及 NV12 合成路径，较 libswscale/OpenCV 约快 7 倍），运行时可用 `ODIN_DISABLE_LIBYUV=1` 禁用。
  - 增加设备专属启动文件 `odin1Lite.launch(.py)`（单目 RGB）和 `odin2Special.launch(.py)`（双目 RGB）。
  - **不兼容变更**：话题/服务命名移除设备型号段，逐设备前缀由 `/{topic_prefix}/{model}/device{N}/` 改为 `/{topic_prefix}/device{N}/`（例如 `/manifold/ODIN2/device0/` → `/manifold/device0/`）。
  - `device_online` 消息 JSON 增加设备型号字段；`device_offline` 由纯 SN 字符串改为 JSON。

- **v3.2.0 / 2026-08-22**：
  - 移除 `control_command.yaml`；数据流开关迁移为 launch 参数。
  - 增加 `set_channel_config` / `get_channel_config` 和 `set_post_process_config` / `get_post_process_config` 服务，支持批量热切换。
  - 增加 `opencv_undistort_node`。
  - 增加 `cloud/raw` 行滤波参数 `enable_row_filter` / `min_row`。
  - 修复点云发布插件 `point_cloud_transport`。

- **v3.1.0 / 2026-08-13**：
  - **不兼容变更**：launch 参数 `operating_mode` 重命名为 `device_mode`。
  - **不兼容变更**：`image_format` 可选值调整，移除 `yuyv`/`nv21`/`rgb24`，新增 `h264`；现支持 `mjpeg|h264`。
  - **不兼容变更**：`sensor_mode` 默认值从 `1`（High Peak）改为 `-1`（不下发，保持设备当前模式）。
  - **不兼容变更**：各传感器 `frame_id` 默认值改为语义化命名（`lidar`、`camera0`、`camera1`、`imu` 等）。
  - 新增 ROS 服务：`set_sync_mode` / `get_sync_mode`、`set_adaptive_param` / `get_adaptive_param`、`reset_initial_pose`、`restore_default_config`、`get_ptp_sync_status`、`set_diag_monitor`。
  - 新增设备端滤波器 launch 参数和 `tf_publish_rate`。

- **v3.0.x 及更早**：初始 v3.x 固件支持、稠密深度/彩色点云节点、点云重投影、Jetson/Rockchip MJPEG 硬件解码、ROS2 Jazzy 支持。

## 8.4 升级方式一：HTTP Dashboard（推荐）

> ⚠️ 升级期间请勿运行 ROS 驱动，请勿断电。建议使用稳定的有线网络。

1. 浏览器访问 **`http://192.168.1.251:8080`**（保持 PC 与设备同网段）。
2. 打开 **Update** 页面，将固件包 `.bin` **拖入上传区域**（或点击选择）。
3. 系统将自动校验签名并安装，过程中页面会展示进度条。
4. 安装完成后设备 **自动重启**；待 Dashboard 重新可访问后，进入 Dashboard 页面校对：
   - **固件版本号** 是否更新到目标版本
   - **设备序列号** 是否一致
   - **温度 / 帧率** 是否回到正常区间

## 8.5 升级方式二：SDK 命令行工具

适用于服务器 / 自动化部署场景。前置条件：已编译 SDK（`module/sdk_api/build/odin_upgrade`）。

```bash
# 自动发现设备并升级
./build/odin_upgrade /path/to/firmware_v<version>.bin

# 指定设备 IP
./build/odin_upgrade /path/to/firmware.bin --device 192.168.1.251

# 指定发现超时
./build/odin_upgrade /path/to/firmware.bin --timeout 5000
```

升级链路基于 **mTLS 双向认证 + Ed25519 签名**，全程加密；签名校验失败会立即中止安装，不会损坏设备。

## 8.6 标定文件管理（同样基于 HTTPS）

- HTTP Dashboard → **Dashboard → 标定文件管理**：上传 / 下载 `camera_calib_<SN>.yaml`
- 命令行工具：

  ```bash
  # 获取标定
  ./build/odin_get_calibration --device 192.168.1.251 --output ./camera_calib.yaml
  # 烧写标定
  ./build/odin_send_calibration ./camera_calib.yaml --device 192.168.1.251
  ```
