# 7. Odin1 Lite 快速启动（Ubuntu）

> 本章用于指导用户在 Ubuntu 系统中成功运行 Odin1 Lite ROS 驱动并取得点云、图像、IMU、里程计等数据。

📄 [下载中文 PDF：O1Lite 快速启动手册 v3.3](assets/pdf/O1Lite快速启动手册-v3.3.pdf)

---

## 7.1 固件版本 / 驱动版本对应关系

| 序号 | 固件版本 | 驱动版本 |
|:-:|:--|:--|
| 1 | v1.3.7 | v0.7.0 |
| 2 | v2.0.x | v0.12.0 |
| 3 | v3.x | v3.x（当前最新：v3.7.0） |

> 请确保固件与驱动版本匹配，版本不匹配可能导致功能异常。`v3.x` 固件必须搭配 `v3.x` 驱动，不可使用 `v0.12.0` 驱动。本文后续的 Service、参数和话题说明以 `v3.7.0` 为准。

## 7.2 硬件组成与安装

| # | 部件 | 说明 |
|:-:|:--|:--|
| 1 | Odin1 Lite 主机 | 一体化 LiDAR + 单目 RGB + IMU 模组 |
| 2 | 电源数据一分二航插线 | 一端航插接主机，另一端分出 DC 头与 RJ45 网口 |
| 3 | 12V/2A DC 电源适配器 | 用户自备（建议 ≥ 24W 电源裕量） |
| 4 | 网线（直连或交换机）| 连接 Odin1 Lite 与 PC |

**安装步骤：**

1. 将航插头按卡槽方向对准 Odin1 Lite 接口插入并锁紧螺纹环。
2. 航插另一端：DC 头接 12V/2A 适配器，RJ45 水晶头接 PC 网口（或交换机）。
3. 上电后设备指示灯应常亮，进入正常工作状态。

> ⚠️ 锁紧航插前请确认卡槽方向，避免插针弯折。

## 7.3 PC 端准备

### 7.3.1 系统要求

| Ubuntu 版本 | 支持的 ROS 版本 |
|:--|:--|
| 20.04 | ROS1 Noetic |
| 22.04 | ROS2 Humble |
| 24.04 | ROS2 Jazzy |

> 请在运行驱动前确认电脑已正确安装并 `source` 对应版本的 ROS 环境。

### 7.3.2 网络配置

Odin1 Lite 通过 **以太网** 与 PC 通信，默认 IP 为 `192.168.1.251`（模组 IP 可根据客户需求更改）。请将 PC 网卡配置到同一网段（例如 `192.168.1.100/24`）。

```bash
# 1. 查看网卡 IP 是否生效
ifconfig

# 2. 测试设备连通性
ping 192.168.1.251
```

> 如果 ping 不通，请重新启用网卡或检查 IP / 子网掩码 / 防火墙是否阻断 UDP 广播（端口 60000-60010）。

### 7.3.3 网卡缓冲区与 ROS_DOMAIN_ID

在运行驱动前，建议放大内核网络接收缓冲区，避免高码率传感器数据导致 UDP 丢包；同一局域网内有多台 PC 运行 ROS2 时，还应设置独立的 `ROS_DOMAIN_ID`。

```bash
# 放大接收缓冲区（建图/重定位稳定运行建议）
sudo sysctl -w net.core.rmem_max=16777216
sudo sysctl -w net.core.rmem_default=8388608
sudo sysctl -w net.core.netdev_max_backlog=50000

# 设置独立的 ROS2 域（1–99；0 表示共享）
export ROS_DOMAIN_ID=1
```

> `export ROS_DOMAIN_ID=...` 仅对当前终端生效，写入 `~/.bashrc` 可永久生效。ROS1 的多机隔离参见 [7.14 多机隔离](#714-多机隔离避免话题串扰)。

## 7.5 部署驱动

以下示例假定驱动包已下载到 `~/Downloads`，工作空间名为 `catkin_ws`。

```bash
# 1. 创建 ROS 工作空间
mkdir -p ~/catkin_ws/src

# 2. 解压驱动并搬运到 src 下
cp ~/Downloads/ros_driver_v3.7.0_release_20261024.tar.xz ~/catkin_ws/src
cd ~/catkin_ws/src
tar -xvf ros_driver_v3.7.0_release_20261024.tar.xz
mv ./ros_driver_v3.7.0_release_20261024/ros_driver ./
rm -rf ros_driver_v3.7.0_release_20261024 ros_driver_v3.7.0_release_20261024.tar.xz
```

完成后目录结构应为：

```
catkin_ws/
└── src/
    └── ros_driver/
        ├── script/build_ros1.sh
        ├── script/build_ros2.sh
        ├── launch/
        ├── config/
        └── ...
```

## 7.7 运行驱动

### ROS1

```bash
cd ~/catkin_ws
source devel/setup.bash

# 默认启动（自动发现设备 + RViz）
roslaunch odin_ros_driver_rev1 odin1Lite.launch

# 指定图像分辨率与帧率
roslaunch odin_ros_driver_rev1 odin1Lite.launch \
    image_width:=640 image_height:=544 image_fps:=30

# 不启动 RViz
roslaunch odin_ros_driver_rev1 odin1Lite.launch start_rviz:=false
```

### ROS2

```bash
cd ~/catkin_ws
source install/setup.bash

# 默认启动
ros2 launch odin_ros_driver_rev1 odin1Lite.launch.py

# 指定图像分辨率与帧率
ros2 launch odin_ros_driver_rev1 odin1Lite.launch.py \
    image_width:=640 image_height:=544 image_fps:=30

# 不启动 RViz
ros2 launch odin_ros_driver_rev1 odin1Lite.launch.py start_rviz:=false
```

成功运行后，RViz 中将自动显示点云与图像。

### 常用启动参数

以下参数在节点启动时读取；修改后需重新启动驱动。完整参数列表可通过 `ros2 launch odin_ros_driver_rev1 odin1Lite.launch.py --show-args` 查看。

| 参数 | 默认值 | 说明 |
|:--|:--|:--|
| `start_rviz` | `true` | 是否启动 RViz |
| `topic_prefix` | `manifold` | 话题前缀根；最终前缀为 `/{topic_prefix}/device{N}/` |
| `device_mode` | `normal` | 启动时设备模式：`normal` 或 `standby` |
| `discovery_timeout_ms` | `2000` | 设备发现超时，单位 ms |
| `image_width` / `image_height` / `image_fps` | `0` | 图像宽、高、帧率；`0` 表示使用设备默认能力 |
| `image_format` | `mjpeg` | 图像格式：`mjpeg` 或 `h264` |
| `filter_confidence_threshold` | `-1` | 设备端置信度滤波阈值；`-1` 表示保持设备默认值 |
| `filter_adaptive_cdf_percentile` | `-1` | 自适应滤波 CDF 百分位（`1..10000`）；`-1` 表示设备默认值 |
| `filter_adaptive_outdoor_thr` | `-1` | 自适应滤波室外距离阈值（mm）；`-1` 表示设备默认值 |
| `filter_range_min_depth` | `-1` | 设备端距离滤波最小有效深度（mm）；`-1` 表示设备默认值 |
| `raw_frame_id` / `gray_image_frame_id` | `lidar` | 原始点云、灰度图像的 `frame_id` |
| `slam_frame_id` / `odom_frame_id` | `odom` | SLAM 点云、里程计父坐标系的 `frame_id` |
| `image_frame_id` / `image2_frame_id` | `camera0` / `camera1` | 相机图像的 `frame_id` |
| `imu_frame_id` | `imu` | IMU 的 `frame_id` |
| `tf_publish_rate` | `0` | TF 定时重发频率（Hz）；`0` 禁用定时重发 |
| `enable_row_filter` | `false` | 是否启用行滤波 |
| `min_row` | `0` | 行滤波最小行号，范围 `0..191`；低于该行的点置零 |
| `confidence_threshold` | `7` | 初始点云置信度阈值（`0..255`）|
| `sensor_mode` | `-1` | 初始 dToF 传感器模式；`-1` 保持设备当前模式 |
| `log_level` | `1` | SDK / ROS 日志级别：`0`=ERROR、`1`=INFO、`2`=WARN、`3`=DEBUG |

## 7.8 参数设置说明

驱动参数分为两类：**启动期参数**只在节点启动时读取；**运行期参数**支持在节点运行中修改并立即生效。除下表及 [7.11 数据流开关](#711-数据流开关) 中标注为可动态修改的参数外，其他参数即使通过 `ros2 param set` 写入参数服务器，也不会应用到节点逻辑，必须通过 launch 参数设置后重启驱动。

### 运行期参数

| 参数 | 范围 / 默认值 | 说明 |
|:--|:--|:--|
| `confidence_threshold` | `0..255` / `7` | 点云置信度阈值，低于该值的点会被置零；在保证无噪点的前提下尽可能小，室内场景建议从 `4` 开始调整 |
| `sensor_mode` | `-1..3` / `-1` | dToF 传感器模式；`-1` 为启动时不下发、保持设备当前模式，`0..3` 的模式含义见 [7.9 长短帧切换](#79-长短帧sensor-mode切换) |
| `log_level` | `0..3` / `1` | SDK / ROS 日志级别：`0`=ERROR、`1`=INFO、`2`=WARN、`3`=DEBUG |

### 设置方式

```bash
# ROS2：查看、读取和修改运行期参数
ros2 param list /odin_ros_driver_node
ros2 param get /odin_ros_driver_node sensor_mode
ros2 param set /odin_ros_driver_node sensor_mode 3
ros2 param set /odin_ros_driver_node confidence_threshold 15
ros2 param set /odin_ros_driver_node log_level 1

# ROS2：通过 launch 配置启动期参数，然后重启驱动
ros2 launch odin_ros_driver_rev1 odin1Lite.launch.py \
    image_width:=640 image_height:=544 image_fps:=30 \
    raw_frame_id:=lidar imu_frame_id:=imu_link

# ROS1：使用 rqt_reconfigure，或通过命令行修改运行期参数
rosrun rqt_reconfigure rqt_reconfigure
rosrun dynamic_reconfigure dynparam set /odin_ros_driver_node sensor_mode 3
```

## 7.9 长短帧（Sensor Mode）切换

Odin1 Lite 支持四种工作模式：

| 枚举 | 模式 | 说明 |
|:-:|:--|:--|
| 0 | HDR | 高动态范围，自动平衡远近 |
| 1 | High Peak（长帧） | 优化强光下接收质量，**适合户外**，近距离精度略低 |
| 2 | Low Peak（短帧） | 优化近距离与小空间噪点，**适合室内**，受强光影响大 |
| 3 | Adaptive | 自适应模式 |

### 方式一：rqt 图形界面

```bash
rqt
# 在 Dynamic Reconfigure 面板中找到 odin_ros_driver_node 节点，
# 调整 sensor_mode 参数即可。
```

### 方式二：命令行参数设置（ROS2）

```bash
source ~/catkin_ws/install/setup.bash

# 切换为 High Peak
ros2 param set /odin_ros_driver_node sensor_mode 1

# 切换为 Low Peak
ros2 param set /odin_ros_driver_node sensor_mode 2
```

## 7.10 建图与重定位操作

> 详细 API 说明请参见 [6. 建图与重定位 API](6.%20map%20and%20relocalizaiton%20api)。
>
> 重定位由 **ROS Driver** 和 **算法 deb 包（`manifold-lc-sdk`）** 共同提供：仅部署 ROS Driver 时，设备可正常输出点云、图像、IMU、里程计等数据，但无法运行建图和重定位算法。
>
> 请确保固件已升级到最新版本。

### 7.10.1 安装重定位算法 deb 包

1. 下载 [download_lc_sdk.sh](assets/code/download_lc_sdk.sh)，在运行 ROS Driver 的主机上执行：

   ```bash
   chmod +x download_lc_sdk.sh
   ./download_lc_sdk.sh
   ```

2. 脚本会检测主机的 CPU 架构及 GPU / NPU、CUDA、TensorRT、OpenVINO、RKNN 等运行环境，并在 `[Download links]` 中输出适用的 `manifold-lc-sdk` 下载链接；优先下载标记为 `RECOMMENDED` 的 deb 包。

3. 下载完成后，在 deb 文件所在目录安装。将以下文件名替换为实际下载的文件名：

   ```bash
   sudo dpkg -i manifold-lc-sdk_<version>_<architecture>.deb
   ```

> ⚠️ 仅下载或编译 ROS Driver 不会安装重定位算法。完成 deb 安装后，再启动 ROS Driver 并执行以下建图或重定位流程。

### 7.10.2 建图（SLAM）

```bash
# 1. 确保驱动已启动且设备已连接

# 2. 切换到 SLAM 模式（开始建图）
ros2 service call /manifold/device0/device_mode \
    odin_ros_driver_rev1/srv/DeviceMode "{mode: 3}"

# 3. 移动设备进行建图...

# 4. 保存地图
ros2 service call /manifold/device0/save_map \
    odin_ros_driver_rev1/srv/SaveMap "{path: '/tmp/odin_map.bin'}"

# 5. 建图完成，切回 Normal
ros2 service call /manifold/device0/device_mode \
    odin_ros_driver_rev1/srv/DeviceMode "{mode: 1}"
```

### 7.10.3 重定位（Relocalization）

```bash
# 1. 切换到 Relocation 模式
ros2 service call /manifold/device0/device_mode \
    odin_ros_driver_rev1/srv/DeviceMode "{mode: 4}"

# 2. 加载之前保存的地图
ros2 service call /manifold/device0/load_map \
    odin_ros_driver_rev1/srv/LoadMap "{path: '/tmp/odin_map.bin'}"

# 3. 移动设备，等待重定位算法完成匹配

# 4. 停止重定位，切回 Normal
ros2 service call /manifold/device0/device_mode \
    odin_ros_driver_rev1/srv/DeviceMode "{mode: 1}"
```

### 7.10.4 ReMap（增量建图）

ReMap（`mode: 5`）在已保存地图的基础上进行重定位，同时扩展地图。适用于需要在已有地图中追加新区域的场景。

```bash
# 1. 切换到 ReMap 模式并加载已有地图
ros2 service call /manifold/device0/device_mode \
    odin_ros_driver_rev1/srv/DeviceMode "{mode: 5}"

ros2 service call /manifold/device0/load_map \
    odin_ros_driver_rev1/srv/LoadMap "{path: '/tmp/odin_map.bin'}"

# 2. 在 RViz 中将 Fixed Frame 设为 device0/map，移动设备采集新区域

# 3. 保存扩展后的地图
ros2 service call /manifold/device0/save_map \
    odin_ros_driver_rev1/srv/SaveMap "{path: '/tmp/odin_map_extended.bin'}"

# 4. 停止 ReMap，切回 Normal
ros2 service call /manifold/device0/device_mode \
    odin_ros_driver_rev1/srv/DeviceMode "{mode: 1}"
```

> 增量保存后的地图通常比原始地图更大。

### 7.10.5 loop-closure 可视化话题

在 SLAM / Relocation / ReMap 模式下，当 `manifold-lc-sdk` 算法 deb 包装好时，会发布以下 loop-closure 可视化话题：

| 话题后缀 | 类型 | 说明 |
|:--|:--|:--|
| `loop_closure/optimization_busy` | `std_msgs/Bool` | 优化器是否正在运行 |
| `loop_closure/optimization_status_marker` | `visualization_msgs/Marker` | 文本标记显示 `IDLE` / `OPTIMIZATION` |
| `loop_closure/optimized_path` | `nav_msgs/Path` | `local_map` 坐标系下优化后的轨迹 |
| `loop_closure/optimized_cloud` | `sensor_msgs/PointCloud2` | `local_map` 坐标系下优化后的全局点云 |
| `loop_closure/map_cloud` | `sensor_msgs/PointCloud2` | `map` 坐标系下加载的地图点云 |

### 7.10.6 确认重定位结果

`load_map` 服务成功返回仅表示地图已被算法会话加载。加载地图后移动设备一段距离，并根据应用侧的定位状态与位姿输出确认重定位是否收敛。

## 7.11 数据流开关

所有数据流开关已从 `config/control_command.yaml` 迁移为 launch 参数。A/B 层参数支持运行期热切换（`ros2 param set` / `rqt_reconfigure` / Service）；C/D/E 层参数仅在启动期生效，修改后需重启驱动。

### A 层：主驱动数据通道（`odin_ros_driver_node`）

| 参数 | 默认值 | 说明 |
|:--|:--|:--|
| `enable_raw_point` | `true` | 原始点云通道 |
| `enable_slam_point` | `true` | SLAM 点云通道 |
| `enable_image0` | `true` | 左 RGB 相机图像通道 |
| `enable_image1` | `false` | 右 RGB 相机图像通道（Odin1 Lite 上无效）|
| `enable_imu` | `true` | IMU 数据通道 |
| `enable_odom_lf` | `true` | 低频里程计通道 |
| `enable_odom_hf` | `true` | 高频里程计通道 |
| `enable_tf` | `true` | TF 变换通道 |

### B 层：后处理输出（`post_process_node`）

| 参数 | 默认值 | 说明 |
|:--|:--|:--|
| `post_process` | `true` | 后处理总开关，仅启动期生效 |
| `send_image_raw` | `true` | 发布解码后的左 RGB 图像 |
| `send_image2_raw` | `false` | 发布解码后的右 RGB 图像（Odin1 Lite 上无效）|
| `send_cloud_render` | `false` | 发布着色点云 |
| `send_undistort` | `false` | 发布去畸变图像 |
| `send_rectify` | `false` | 发布校正图像及 `camera_info` |
| `send_opencv_undistort` | `false` | 启用 OpenCV 去畸变节点 |

### C/D/E 层：启动期功能开关

| 参数 | 节点 | 默认值 | 说明 |
|:--|:--|:--|:--|
| `enable_reprojection` | `pointcloud_reprojector_node` | `false` | 启用点云重投影叠加 |
| `enable_pointcloud_to_depth` | `pointcloud_to_depth_node` | `false` | 启用点云 → 稠密深度图 |
| `enable_depth_to_pointcloud` | `depth_to_pointcloud_node` | `false` | 启用深度图 → 稠密彩色点云 |

```bash
# 单通道热切换
ros2 param set /odin_ros_driver_node enable_raw_point false
ros2 param set /postprocess send_undistort true

# 批量切换主驱动通道：0=关，1=开，-1=保持当前；未列出字段默认 0
ros2 service call /manifold/device0/set_channel_config \
    odin_ros_driver_rev1/srv/SetChannelConfig \
    "{enable_raw_point: -1, enable_slam_point: 0, enable_image0: -1, enable_image1: -1, enable_imu: -1, enable_odom_lf: -1, enable_odom_hf: -1, enable_tf: -1}"

# 批量切换后处理输出
ros2 service call /manifold/postprocess/set_post_process_config \
    odin_ros_driver_rev1/srv/SetPostProcessConfig \
    "{send_image_raw: -1, send_image2_raw: -1, send_cloud_render: -1, send_undistort: 1, send_rectify: -1, send_opencv_undistort: -1}"
```

> 调用 `set_channel_config` / `set_post_process_config` 时，所有不想修改的字段必须显式设为 `-1`，否则未列出的字段会被默认置 `0` 而意外关闭对应数据流。

> ℹ️ Odin1 Lite 为单目 RGB。`enable_image1`、`send_image2_raw` 及双目 / 视差点云相关参数在 Odin1 Lite 上不会发布数据。

### 录制 ROS2 rosbag

录包前请确认已配置 `ROS_DOMAIN_ID` 并放大网卡缓冲区（参见 [7.3.3](#733-网卡缓冲区与-ros_domain_id)）。ROS2 建议使用驱动提供的 QoS 覆盖文件，避免高频话题丢包：

```bash
ros2 bag record -a \
  --qos-profile-overrides-path ~/catkin_ws/src/ros_driver/config/rosbag2_qos.yaml
```

ROS1 使用 TCPROS，无需 QoS 覆盖文件；`rosbag record -a` 即可。

## 7.14 多机隔离（避免话题串扰）

多台 PC 在同一局域网启动驱动时，相同话题会互相干扰。

**ROS2：** 设置独立 `ROS_DOMAIN_ID`

```bash
echo $ROS_DOMAIN_ID            # 查看，空白或 0 表示共享
export ROS_DOMAIN_ID=1         # 1–99；0 为共享
```

**ROS1：** 限制仅本机或更换端口

```bash
# 推荐
export ROS_LOCALHOST_ONLY=1

# 或：使用其他端口
roscore -p 11312
export ROS_MASTER_URI=http://localhost:11312
```

> 上述命令只对当前终端生效，永久生效请追加到 `~/.bashrc`。
