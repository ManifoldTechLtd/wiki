# 10. 重定位地图获取手册

## 10.1 说明

Odin1 Lite 提供重定位功能，支持以下方案获取重定位地图（`.bin` 文件）：

| 方案 | 说明 |
|:-:|:--|
| 1 | 使用 Odin1 Lite SLAM 模式直接生成 bin 文件（推荐）|
| 2 | 使用留形手持扫描仪采集 lx 数据，通过 Mindcloud 导出 bin 文件 |

## 10.2 方案 1：SLAM 模式直接建图（推荐）

这是最简单的方式，通过 ROS 服务即可完成：

```bash
cd ~/catkin_ws
source install/setup.bash

# 1. 切换到 SLAM 建图模式
ros2 service call /manifold/device0/device_mode \
    odin_ros_driver_rev1/srv/DeviceMode "{mode: 3}"

# 2. 移动 Odin1 Lite 采集环境数据...

# 3. 采集结束后保存地图
ros2 service call /manifold/device0/save_map \
    odin_ros_driver_rev1/srv/SaveMap "{path: '/tmp/odin_map.bin'}"

# 4. 切回 Normal
ros2 service call /manifold/device0/device_mode \
    odin_ros_driver_rev1/srv/DeviceMode "{mode: 1}"
```

地图文件将保存到指定路径（如 `/tmp/odin_map.bin`）。

> 也可在 SLAM 建图完成后，通过 ReMap（`device_mode=5`）在已有地图基础上继续增量建图并保存扩展后的地图。增量保存后的地图通常比原始地图更大。

> ❗ 建图期间请勿 `Ctrl+C` 退出驱动，必须先调用 `save_map` 保存地图。

## 10.3 方案 2：留形手持扫描仪采集 lx + Mindcloud 导出

如无留形手持设备，请选择其他方案。

1. Q9000 连接手机，使用 Mindcloud Go 进行数据扫描
2. 扫描结束后将工程文件导出到本地
3. 使用 Mindcloud 处理 lx 文件，在后处理中点击“导出地图”按钮，获取重定位 bin 文件

## 10.4 地图下载（HTTP Dashboard）

也可以通过设备内置 HTTP Dashboard 下载重定位地图：

1. 浏览器访问 `http://192.168.1.251:8080`
2. 在 Dashboard 页面找到“地图文件下载”功能
3. 下载 bin 文件到本地
