# 11. 维护与故障排除

## 11.1 日常维护

1. **清洁规范：**
   - 使用气吹清除镜头灰尘
   - 使用干净的软布擦拭设备外壳
   - ⚠️ 禁止使用腐蚀性溶剂擦拭窗口玻璃，腐蚀性溶剂会破坏玻璃表面镀膜；当腐蚀性溶剂从窗口玻璃边缘缝隙进入，会腐蚀玻璃的防水背胶，导致防水失效。禁用的腐蚀性溶剂包含但不限于：酒精、异丙醇、白电油、松节油等。

2. **存储条件：**
   - 温度：-20℃ ~ 60℃
   - 湿度：< 85% RH

## 11.2 常见故障排除

> 更多问题参见 [13. FAQ](13.%20FAQ)。

| 故障现象 | 可能原因 | 解决方法 |
|:--|:--|:--|
| 上电后设备无响应 | 供电异常 | 检查 12V 适配器输出、DC 头是否插紧、航插是否锁紧 |
| `ping 192.168.1.251` 不通 | PC 与设备不同网段 / 网线 / 网口问题 | 设置 PC 网口为 `192.168.1.x/24`；重启网口；更换网线 |
| HTTP Dashboard 无法访问 | 端口 8080 被防火墙拦截 / 设备未完全启动 | 关闭防火墙或放行 8080；等待 ~30s 重试 |
| 驱动运行后无数据输出 | UDP 广播被防火墙拦截 / 网络未同网段 | 放行 UDP 60000–60010；确认 PC 与设备在同一网段。设备发现、网卡选择和 UDP 端口由 SDK 自动处理，无需配置 `device_ip` |
| RViz 提示 TF 变换失败 | 设备原始 TF 频率低，时间戳无法插值 | 启动时设置 `tf_publish_rate:=50`；推荐范围 50–200 Hz，`0` 为禁用 |
| `post_process_node` 发布首帧图像时崩溃 | 系统 OpenCV 与 ROS 的 `cv_bridge` 链接版本不一致 | 在当前工作空间重新编译与系统 OpenCV 匹配的 `vision_opencv` / `cv_bridge`，详见 [13. FAQ](13.%20FAQ) |
| 重定位一直失败 | 设备静止 / 地图文件路径错误 / 算法会话未就绪 | 移动设备；检查 bin 文件路径；确认已安装 `manifold-lc-sdk` 且在对应模式下调用地图服务 |
| 建图/重定位漂移或丢包严重 | 网卡接收缓冲区不足 / UDP 丢包 | 启动驱动前放大缓冲区：`sudo sysctl -w net.core.rmem_max=16777216 net.core.rmem_default=8388608 net.core.netdev_max_backlog=50000` |
| `ros2 service call` 无响应 | 服务名称错误（大小写不匹配）| 用 `ros2 service list` 确认实际服务名；v3.x 设备型号不再出现在话题/服务路径中 |
