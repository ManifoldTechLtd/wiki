# Odin 系列

专为具身智能设备打造的高性能全场景空间记忆模组

---

## 产品

### [Odin1](./odin1/)

深度融合多传感器高性能硬件与MindSLAM算法，为具身智能和自动移动机器人提供**高性能、高集成、高鲁棒**的空间感知与记忆能力

### [Odin1 Lite](./odin1lite/)

集 LiDAR + 单目 RGB + IMU 于一体的紧凑型空间记忆模组，采用以太网连接，为尺寸与成本敏感型机器人、自主导航平台提供**轻量化、易集成、高可靠**的三维感知与空间记忆能力
