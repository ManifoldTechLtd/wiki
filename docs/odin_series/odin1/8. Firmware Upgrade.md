# 8. 固件升级

## 固件链接

## 固件更新时间

2026-02-11

## 固件更新信息

 1. 增加摄像头和激光雷达切换帧率功能（10/14.5hz）
 2. 增加里程计协方差输出
 3. 高冲击场景优化
 4. 优化回环检测和重定位，降低误匹配率
 5. 支持升级工具运行在ARM架构设备上

## ROS Driver 更新信息

 1. 修改获取地图失败，其他命令处于锁定状态的问题
 2. 增加ros driver在yaml文件设置帧率的功能(100:10FPS  145:14.5FPS)
 3. 增加ntp-like(模拟ntp方式)时间同步功能
 4. 增加 imu 数据保存功能（打开recorddata，支持cloudmind后处理）
 5. 增加cloud_slam 投影到原始图片demo

## 固件升级操作

**注意：升级过程中请勿运行驱动，运行过程中请勿断电**

1. 通过链接下载固件
2. 解压文件
3. 执行升级脚本
```shell
./odin1_firmware_update_tool_0.4.5_amd64_ubuntu22.04 odin1_firmware_update_0.10.0.tar.gz 
```
等待升级完成，设备会自动重启
