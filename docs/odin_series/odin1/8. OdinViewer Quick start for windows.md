# 8. OdinViewer 快速启动

📄 [Download English PDF: OdinViewer v0.1.1 User Manual](./assets/pdf/OdinViewer-v0.1.1-User-Manual.pdf)

📄 [下载中文PDF：OdinViewer v0.1.1 使用手册](./assets/pdf/OdinViewer%20v0.1.1%20使用手册（零基础版）.pdf)


## 8.1 硬件设备安装
硬件组成：Odin主机、数据线、电源线（电源适配器需用户自行准备）
PC端：windows系统

## 8.2 软件

- [Odin Viewer](./assets/software/odinviewer_20260821_Windows_Release.zip)

## 8.3 设备连接PC
- 使用12V2A的电源适配器为Odin主机供电
- 将数据线插入电脑主机USB接口

## 8.4 安装驱动

- 通过8.2链接下载Odin Viewer，解压后找到USBTools文件夹，双击运行zadig-2.9.exe
- 点击下拉菜单找到hawk的设备（即Odin1），选择后点击"Install Driver"按钮，等待安装完成
> 注意: 一台电脑只需要安装一次，后续使用无需重复安装

## 8.5 运行软件

双击运行OdinViewer.exe运行软件，将自动显示点云和图像数据

## 8.6 录制数据

- OdinViewer仅支持录制olx格式数据，点击右下角Start Recording按钮开始录制,再次点击Stop Recording按钮停止录制
- 数据将保存在软件同级目录下的recorddata文件夹中
