## 固件更新信息

本次为应用与系统固件的联合更新：应用与内核配合修复了 RGB 帧时间戳精度问题，使时间戳更接近真实曝光（积分）中点，并在整个手动曝光范围内保持可靠；同时修复了设备启动时应用启动失败的问题。系统固件体积由约 590MB 精简至约 225MB（-60%），显著缩短 OTA 下载与烧写时间。

### Bug 修复

1. **修复 RGB 帧时间戳精度问题**

   优化曝光寄存器配置，RGB 帧时间戳现在与真实曝光（积分）中点高度对齐。

2. **统一 JPEG/NV12 时间戳**

   消除了 JPEG 与 NV12 直发通路之间的时间戳差异。

3. **修复手动曝光下的时间戳可靠性问题（内核）**

   修复了长时间手动曝光下时间戳不准确，以及极短曝光下大量帧缺少硬件时间戳的问题；现在整个手动曝光范围内均可提供可靠的时间戳。

4. **修复设备启动时应用启动失败的问题**

   修复了因 USB 设备尚未就绪导致的开机启动失败问题。

### 系统更新

1. **系统镜像精简**

   完整固件镜像由约 590MB 缩减至约 225MB（-60%），显著缩短 OTA 下载与烧写时间。

### 兼容性说明

本次更新不包含破坏性变更，无需额外迁移。

## 固件升级操作

📄 [下载固件升级工具详细使用说明（PDF）](assets/pdf/Odin1升级工具使用说明.pdf)

> ℹ️ 升级工具版本说明：
> - 0.14.3 固件包已内置 **0.6.0** 升级工具（兼容所有固件版本），并附带 `update.sh` 一键升级脚本
> - `update.sh` 会自动识别主机架构（amd64 / aarch64），依次尝试 0.6.0 → 0.5.0 → 0.4.9 工具
> - 历史规则：当前固件 ≤ 0.12.4 → 请使用 **0.4.9** 版本升级工具；当前固件 ≥ 0.13.0 → 请使用 **0.5.0** 版本升级工具

**升级前请注意：**

- 升级前请关闭 ROS driver 并重启设备。
- 升级过程中请勿断开电源。
- 建议使用 USB 3.0 接口；USB 2.0 也可升级，但过程中可能出现断连，需要重新升级。
- 升级完成后建议将设备完全断电再重新上电。
- 升级后请使用最新版 `odin_ros_driver`。

1. 通过链接下载固件包并解压
2. 进入解压目录，执行一键升级脚本：
```shell
./update.sh
```
3. 也可手动指定固件包与工具版本：
```shell
# 以X86平台升级为例
./odin1_firmware_update_tool_0.6.0_amd64 odin1_firmware_update_0.14.3.tar.gz
```
等待升级完成，设备会自动重启
