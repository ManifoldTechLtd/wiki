## 固件更新时间

2026-06-18

## 固件更新信息

1. 更稳定的 IMU 输出

高频 IMU 数据输出更加稳定，即使在系统负载较高的情况下，也能显著减少时间戳异常和数据抖动问题。

2. 更可靠的地图传输

传输重定位地图（Relocalization Map）时，不再导致设备摄像头视频流中断或传输过程中意外终止。

3. 断电恢复能力增强

设备在意外断电后重新启动时，能够保持原有配置不丢失，不再因配置文件损坏而导致 SLAM 无法启动。

4. 更稳定的 USB 连接

当主机重启或 USB 临时断开后，设备能够正常重新连接，不再出现数据乱码、传输卡死或残留文件阻碍后续连接的问题。

5. 更可靠的标定数据加载

修复了极少数情况下因标定数据异常导致设备意外重启的问题。

## 升级注意事项（Upgrade Notes）

- 设备与主机 SDK 之间的通信协议已经更新。

- 请务必同时升级设备固件和主机端 SDK/驱动程序。

- 如果设备端与主机端版本不匹配，可能会导致连接不稳定、通信异常等问题。

## ROS Driver 更新信息

1. 适配0.12.0固件

2. 降低cloud_slam的延迟

3. 提升slam模式获取地图稳定性

4. 优化arm平台usb2.0状态加载地图失败问题

## 固件升级操作

**注意：升级过程中请勿运行驱动，运行过程中请勿断电,建议使用USB3.0接口，2.0接口也可以升级，但是过程中可能出现断连，需要重新C掉升级**

1. 通过链接下载固件
2. 解压文件
3. 执行升级脚本(升级工具支持x86平台后缀为amd64,arm平台后缀为aarch64,请根据自己平台选择对应工具)
```shell
# 以X86平台升级为例
./odin1_firmware_update_tool_0.4.8_amd64 odin1_firmware_update_0.12.0.tar.gz  
```
等待升级完成，设备会自动重启
