## 固件更新信息

### 功能改进

1. **优化高负载场景下的 USB 传输调度**

   当深度点云等高带宽数据流满负载传输时，优先保障命令、心跳和文件传输通道的及时响应，避免因带宽竞争导致控制延迟。

2. **增强设备重连后的自动恢复能力**

   设备重新连接主机后，所有数据通道自动恢复，无需重启设备或人工干预，提高现场部署中的容错能力。

3. **增强文件传输的稳定性**

   地图保存等文件传输任务新增超时保护机制，在任务失败时能够及时终止或重试，避免长时间无响应。

### Bug 修复

1. **修复 USB 2.0 高负载场景下可能出现的不可恢复断连问题**

   此前在带宽接近饱和时，设备可能发生断连且主机无法再次识别设备。现在即使在极端带宽条件下也能保持稳定连接。

2. **修复高负载场景下深度流显示卡死的问题**

   此前多个数据流同时传输时，部分深度数据帧可能不完整，导致点云显示长时间停止更新。现在能够保证数据帧完整传输，提高 SLAM 等应用的稳定性。

3. **修复设备反复重连后资源逐渐累积的问题**

   提升设备长时间运行的稳定性。

4. **修复文件传输任务可能卡死的问题**

   此前地图保存等文件传输任务可能出现卡住且无法完成的情况。现在能够确保任务可靠完成，并在失败时及时重试。

5. **修复特殊场景下传感器时间戳精度问题**

   提升多传感器之间的时间同步精度，改善 SLAM 融合等应用的数据质量。

6. **优化 OTA 升级速度**

   精简 OTA 升级流程，显著缩短升级所需时间。

## 升级注意事项

- 设备与主机 SDK 之间的通信协议已经更新。

- 请务必同时升级设备固件和主机端 SDK/驱动程序。

- 如果设备端与主机端版本不匹配，可能会导致连接不稳定、通信异常等问题。

- 运行本固件要求驱动版本不低于 **0.13.0**。

## 固件升级操作

📄 [下载固件升级工具详细使用说明（PDF）](assets/pdf/odin1固件升级工具使用说明.pdf)

> ℹ️ Odin1 固件 0.13.0 起升级协议有变动：
> - 当前固件 ≤ 0.12.4 → 请使用 **0.4.9** 版本升级工具
> - 当前固件 ≥ 0.13.0 → 请使用 **0.5.0** 版本升级工具

**注意：升级过程中请勿运行驱动，运行过程中请勿断电,建议使用USB3.0接口，2.0接口也可以升级，但是过程中可能出现断连，需要重新C掉升级**

1. 通过链接下载固件
2. 解压文件
3. 执行升级脚本(升级工具支持x86平台后缀为amd64,arm平台后缀为aarch64,请根据自己平台选择对应工具)
```shell
# 以X86平台升级为例
./odin1_firmware_update_tool_0.5.0_amd64 odin1_firmware_update_0.14.1.tar.gz
```
等待升级完成，设备会自动重启
