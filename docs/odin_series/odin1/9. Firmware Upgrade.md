## 固件更新信息

本次更新聚焦定位算法的自愈能力与相机曝光控制：切换地图后定位算法自动重启、最大曝光时间支持远程可调；同时解耦传感器采集与算法计算、修正深度点云强度口径、降低大文件传输耗时，并新增异常自恢复机制。此外修复了重复启停、启停应答错配、停止超时等稳定性问题。本次更新同时升级 MCU，升级耗时较以往更长。

### 新功能

1. **切换地图后自动重启定位算法**

   上位机下发地图模式切换或更新重定位地图文件后，定位与建图算法会自动重启并继续工作，无需人工重启设备或重新下发启动指令。

2. **最大曝光远程可调**

   上位机可查询当前曝光路由并动态设置最大曝光时间；设备按当前帧率档位校验上限，超出范围的请求会返回明确的拒绝结果，不会静默生效。

### 改进

1. **曝光控制更智能**

   开启图像流时，设备按当前帧率档位自动应用经过调优的默认最大曝光，在夜间亮度与运动拖影之间取得更好的平衡；各帧率档位的曝光上限同步重新标定；曝光设置失败会如实返回失败状态，不再被误报为成功。

2. **图像与 IMU 数据更连续**

   传感器数据采集与定位建图计算相互解耦，算法侧计算量波动或算法重启不再造成上位机收到的图像、IMU 数据中断。

3. **深度点云强度更准确**

   升级深度相机 SDK，点云强度信息输出口径更加准确一致，避免点云在强度过滤环节被误丢弃。

4. **大文件传输更高效**

   通过上位机下发地图等大文件时，接收耗时明显降低。

5. **异常后可自行恢复**

   极少数异常情况下设备会无响应、需人工重启；现在发生异常时会自动退出并重新拉起，上位机侧可继续正常下发指令，减少现场人工干预。

### Bug 修复

1. **重复或多路启停指令不再导致状态异常**

   上位机重复或交错下发启动、停止指令时，设备不会重复执行耗时数秒的停止流程，也不会出现启动与停止状态相互覆盖的错乱。

2. **启停应答与实际指令一一对应**

   每次启动或停止都会返回属于自己的应答，不会再吞掉上位机的停止应答，也不会凭空回复成功。

3. **停止超时可自动收敛**

   运行中的算法进程若在超时内未退出，会被强制结束，保证下一次启动一定能重新建立数据链路，且设备不留残留实例。

4. **停止与重新建链期间不再卡死或上报脏数据**

   停止过程中优先中断数据读取，重建前独占数据通道，上一轮残留的数据帧不会被当成新数据上报。

5. **停止定位算法时不再偶发卡死**

   优化了停止流程中多线程共享资源的释放顺序，消除持锁异常导致的设备无响应。

6. **重复启动不会重复拉起定位算法**

   多次下发启动指令时，定位与建图算法只会运行一份。

### 兼容性说明

本次更新不包含破坏性变更，上位机接口无需额外适配。

## 升级注意事项

- 运行本固件要求驱动版本不低于 **0.13.0**。

- 推荐使用驱动版本 **0.14.5**。

- 本次更新会同时升级 MCU，升级耗时较以往更长，请耐心等待，升级过程中切勿断电。

- 本次固件更新不包含破坏性变更，无需额外迁移。

## ROS Driver 更新信息

驱动获取：<https://github.com/manifoldsdk/odin_ros_driver.git>

当前版本：0.14.5（最低要求 0.13.0）

1. 新增最大曝光设置接口：`control_command.yaml` 增加 `ae_max_exposure_time`（AE 曝光上限，单位 ms），并提供 `/odin1/set_ae_max_exposure` 服务（ROS1 / ROS2）

2. 修复设备热插拔导致的驱动崩溃

3. 更新 SDK：曝光上限超过当前帧率档位的默认值（10.26 / 14.47 / 28.92 Hz 对应 30 / 20 / 15 ms）时打印警告，但请求仍会下发

4. 更新 SDK：设备已处于目标状态时，`lidar_open_device` / `lidar_close_device` / `lidar_set_mode` / `lidar_start_stream` / `lidar_stop_stream` 直接跳过（打印警告并返回 0），避免重复执行启停流程

## 固件升级操作

📄 [下载固件升级工具详细使用说明（PDF）](assets/pdf/Odin1升级工具使用说明.pdf)

> ℹ️ 升级工具版本说明：
> - 0.14.3 及之后的固件包已内置 **0.6.0** 升级工具（兼容所有固件版本），并附带 `update.sh` 一键升级脚本
> - `update.sh` 会自动识别主机架构（amd64 / aarch64），依次尝试 0.6.0 → 0.5.0 → 0.4.9 工具
> - 历史规则：当前固件 ≤ 0.12.4 → 请使用 **0.4.9** 版本升级工具；当前固件 ≥ 0.13.0 → 请使用 **0.5.0** 版本升级工具

**升级前请注意：**

- 升级前请关闭 ROS driver 并重启设备。
- 升级过程中请勿断开电源；本次更新包含 MCU 升级，中途断电可能导致设备无法正常启动。
- 建议使用 USB 3.0 接口；USB 2.0 也可升级，但过程中可能出现断连，需要重新升级。
- 升级完成后建议将设备完全断电再重新上电。
- 升级后请使用最新版 `odin_ros_driver`。

1. 通过链接下载固件包并解压
2. 进入解压目录，执行一键升级脚本：
```shell
./update.sh
```
3. 也可手动指定固件包与工具版本：
```shell
# 以X86平台升级为例
./odin1_firmware_update_tool_0.6.0_amd64 odin1_firmware_update_0.14.7.tar.gz
```
等待升级完成，设备会自动重启
