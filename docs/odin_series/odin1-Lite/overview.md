# Odin1-Lite Overview

Odin1-Lite is a lightweight variant of the Odin Series designed for fast integration and cost-sensitive deployments.

## Key highlights

- Compact form factor for embedded and mobile platforms
- Multi-sensor perception capabilities for indoor/outdoor operation
- Designed to work with the same SDK / API style as the rest of the Odin Series

This product folder will contain:

- Getting started and quick setup
- Hardware overview and interfaces
- Data outputs and SDK usage
- Firmware and troubleshooting
