## Firmware Release Notes

This release is a joint application + system firmware update: RGB frame timestamp accuracy is fixed collaboratively between the application and the kernel, bringing timestamps closer to the true exposure (integration) midpoint and keeping them reliable across the entire manual exposure range; a boot-time app startup failure is also fixed. The system firmware is slimmed from ~590 MB to ~225 MB (-60%), sharply reducing OTA download and flashing times.

### Bug Fixes

1. **Fixed RGB frame timestamp accuracy**

   Optimized exposure register configuration so that RGB frame timestamps now align closely with the true exposure (integration) midpoint.

2. **Unified JPEG/NV12 timestamps**

   Eliminated the timestamp discrepancy between the JPEG and NV12 direct-send paths.

3. **Fixed timestamp reliability under manual exposure (kernel)**

   Fixed inaccurate timestamps with long manual exposures, and fixed an issue where very short exposures left many frames without a hardware timestamp; reliable timestamps are now available across the entire manual exposure range.

4. **Fixed app startup failure at boot**

   Fixed a boot-time startup failure caused by the USB device not being ready yet.

### System Updates

1. **System image slimming**

   The full firmware image shrinks from ~590 MB to ~225 MB (-60%), sharply reducing OTA download and flashing times.

### Compatibility Notes

This release contains no breaking changes and requires no additional migration.

## Upgrade Procedure

📄 [Download detailed Firmware Upgrade Tool instructions (PDF)]({{ '/odin_series/odin1/assets/pdf/Odin1_Firmware_Update_Tool_User_Guide.pdf' | relative_url }})

> ℹ️ Upgrade tool versions:
> - The 0.14.3 firmware package bundles upgrade tool **0.6.0** (compatible with all firmware versions) and the `update.sh` one-click upgrade script.
> - `update.sh` auto-detects the host architecture (amd64 / aarch64) and tries tools 0.6.0 → 0.5.0 → 0.4.9 in order.
> - Historical rule: firmware ≤ 0.12.4 → tool **0.4.9**; firmware ≥ 0.13.0 → tool **0.5.0**.

**Before upgrading:**

- Stop the ROS driver and reboot the device before upgrading.
- Do not disconnect power during the upgrade.
- A USB 3.0 port is recommended; USB 2.0 also works, but disconnections may occur during the upgrade and require restarting the upgrade.
- After the upgrade, fully power off the device and then power it on again.
- Use the latest `odin_ros_driver` after the upgrade.

1. Download and extract the firmware package from the link above.
2. Enter the extracted directory and run the one-click upgrade script:

```shell
./update.sh
```

3. Alternatively, specify the firmware package and tool version manually:

```shell
# Example for an x86 platform
./odin1_firmware_update_tool_0.6.0_amd64 odin1_firmware_update_0.14.3.tar.gz
```

Wait for the upgrade to complete; the device will reboot automatically.
