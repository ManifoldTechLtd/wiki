# 9. Firmware Upgrade

## Firmware Download

[Download Odin1 firmware 0.11.3](https://vvcazjv268.feishu.cn/drive/folder/HdNgfilAvlucPNdraUrcyCmznPf?from=from_copylink)

## Firmware Release Date

2026-04-08

## Firmware Release Notes

1. Fix the issue where the module had to be restarted on heartbeat timeout.
2. Add the photo dead-zone (mask) configuration feature.
3. Add a dynamic initialization feature.

## ROS Driver Release Notes

1. Add IMU smoothed publishing (up to 400 Hz).
2. Add publishing of dead-zone-masked images, configurable via the configuration file.
3. Fix incorrect reprojection.
4. Add an overlay visualization topic that fuses the reprojection with the RGB image at a configurable transparency, for an intuitive evaluation of projection and geometric alignment accuracy.
5. Fix a crash in the upgrade tool when the module's SoC version is below 0.5.0.

## Upgrade Procedure

**Note: Do not run the driver during the upgrade, and do not power off during the process. A USB 3.0 port is recommended; USB 2.0 also works, but disconnections may occur during the upgrade and require restarting the upgrade with Ctrl+C.**

1. Download the firmware via the link above.
2. Extract the archive.
3. Run the upgrade script (the upgrade tool is available with two suffixes: `amd64` for x86 platforms and `aarch64` for ARM platforms — pick the one that matches your platform):

```shell
# Example for an x86 platform
./odin1_firmware_update_tool_0.4.6_amd64 odin1_firmware_update_0.11.3.tar.gz
```

Wait for the upgrade to complete; the device will reboot automatically.
