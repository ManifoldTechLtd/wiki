# Odin1 Lite

| Feature | Specification |
|:---|:---|
| **Compact spatial perception** | 50 m @ 90 % reflectivity / 25 m @ 10 % reflectivity · 120° × 90° ultra-wide FOV · up to 430,000 pts/s · single RGB global shutter |
| **Spatial memory and localization** | ±5 cm + 1 % built-in SLAM localization accuracy · supports mapping, relocalization and ReMap incremental mapping |
| **Compact industrial design** | 274 g lightweight body · approx. 69 mm × 69 mm × 58 mm compact size · IP66 · 9–24 V wide-voltage input · 50G shock resistance |
