# 10. Relocalization Map Acquisition Guide

## 10.1 Description

Odin1 Lite provides relocalization functionality and supports the following schemes to obtain relocalization maps (`.bin` files):

| Scheme | Description |
|:-:|:--|
| 1 | Use Odin1 Lite SLAM mode to directly generate a bin file (recommended) |
| 2 | Use a Liuxing handheld scanner to collect lx data, then export a bin file through Mindcloud |

## 10.2 Scheme 1: Direct Mapping in SLAM Mode (Recommended)

This is the simplest way; it can be completed through ROS services:

```bash
cd ~/catkin_ws
source install/setup.bash

# 1. Switch to SLAM mapping mode
ros2 service call /manifold/device0/device_mode \
    odin_ros_driver_rev1/srv/DeviceMode "{mode: 3}"

# 2. Move Odin1 Lite to collect environment data...

# 3. Save the map after collection
ros2 service call /manifold/device0/save_map \
    odin_ros_driver_rev1/srv/SaveMap "{path: '/tmp/odin_map.bin'}"

# 4. Switch back to Normal
ros2 service call /manifold/device0/device_mode \
    odin_ros_driver_rev1/srv/DeviceMode "{mode: 1}"
```

The map file will be saved to the specified path (e.g., `/tmp/odin_map.bin`).

> After SLAM mapping is complete, you can also use ReMap (`device_mode=5`) to continue incremental mapping on the existing map and save the extended map. The incrementally saved map is usually larger than the original map.

> ❗ Do not `Ctrl+C` exit the driver during mapping; you must call `save_map` to save the map first.

## 10.3 Scheme 2: Liuxing Handheld Scanner lx Collection + Mindcloud Export

If you do not have a Liuxing handheld device, please choose another scheme.

1. Connect Q9000 to a phone and use Mindcloud Go for data scanning.
2. After scanning, export the project file to the local machine.
3. Use Mindcloud to process the lx file, and click the "Export Map" button in post-processing to obtain the relocalization bin file.

## 10.4 Map Download (HTTP Dashboard)

You can also download the relocalization map through the device's built-in HTTP Dashboard:

1. Open a browser and visit `http://192.168.1.251:8080`.
2. Find the "Map File Download" function on the Dashboard page.
3. Download the bin file to the local machine.
