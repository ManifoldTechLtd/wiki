Welcome to the official MindPalace **Odin1 Lite** Wiki. This documentation covers the complete product content including hardware, installation and deployment, data interfaces, algorithm usage, firmware upgrade and frequently asked questions.

> Odin1 Lite is a compact spatial-memory module integrating LiDAR + RGB camera + IMU (**single RGB**). It uses **Ethernet connection** (factory IP `192.168.1.251`), and provides ROS1 / ROS2 drivers and an HTTP Dashboard.

---

## Quick Start

1. Power on the device → connect the network cable to the PC → set the PC to `192.168.1.x/24`.
2. Open a browser and visit `http://192.168.1.251:8080` to check device status.
3. Deploy the driver: see [7. Odin1 Lite Quick Start (Ubuntu)](./7.%20Odin1Lite%20Quick%20start%20for%20ubuntu.html).
