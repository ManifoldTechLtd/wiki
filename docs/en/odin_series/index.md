# Odin Series

A high-performance, all-scenario spatial-memory module designed for embodied-intelligence devices.

---

## Products

### [Odin1](./odin1/)

Deeply fused multi-sensor hardware combined with the MindSLAM algorithm — delivering **high performance, high integration and high robustness** spatial perception and memory for embodied AI and autonomous mobile robots.

### [Odin1 Lite](./odin1lite/)

A compact spatial-memory module integrating LiDAR + single RGB + IMU. It uses Ethernet connectivity and provides **lightweight, easy-to-integrate and highly reliable** 3D perception and spatial memory for size- and cost-sensitive robots and autonomous navigation platforms.
