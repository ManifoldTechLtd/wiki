# 1.产品概述

## MindPalace Pocket2&Pro
Pocket2是一款高精度专业级三维数据采集与智能处理设备，融合点云扫描、全景图像采集与细目影像记录于一体。设备内置高性能MindSLAM™算法，实现三维数据的实时采集与处理，显著提升现场作业效率。Pocket2广泛适用于数字孪生构建、设施运维、机器人仿真训练等前沿场景，同时服务于消防、公安、交通、林业等应急与调查行业。通过与MindCloud平台的深度联动，Pocket2支持从二维图像到三维模型的无缝生成，打通数字孪生“采→算→模”的全链路工作流。<br>
Pocket2 Pro版本在标准版基础上增加了顶置双1200万像素全景相机模组，提供更高分辨率的场景采集数据和卓越的3DGS渲染效果，满足专业用户更高标准的需求。
